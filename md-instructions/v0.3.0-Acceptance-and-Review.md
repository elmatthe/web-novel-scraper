## Recovering the Lord of Mysteries 2 (.com) run (composite headings)

1. Restart through `Setup_and_Run-Web-Novel-Scraper.bat` so the fixed program loads.
2. Choose **Free Web Novel (.com)** and **Lord of Mysteries 2**, the same Start/End and file types as the
   incomplete run, and the output folder that holds that run. Tick **Resume Existing Run** and pick the
   run's own numbered folder. Do not tick any refresh box; nothing needs refreshing.
3. Run. It fetches only the missing chapters (1130–1138) when files are separate; with grouped files it
   rebuilds the unfinished group without shrinking it. A browser window may appear; leave it on screen.
4. Expect headings like `Chapter 1129.1-1130: Initiative` and `Chapter 1130-1131: Individual
   Preparations` (and `1131-1132` … `1137-1138` for the rest), then run
   `python files\audit_run.py "<the run folder>" --pdf-text` (it ends `All checks passed.` when whole).
   If the folder cannot be resumed, start a new run for the same range; nothing is lost.

## Before you start

- **Where things go:** runs land in `Downloads\Web-Novel-Scraper-Outputs\<novel>-N\` (`PDF\`, `TXT\`,
  plus `run-journal.jsonl`, `run-selection.json`, `run-audit.json`). Saved chapter lists are in
  `files\runtime-data\chapter-lists\<website>\`, saved pages in `files\cache\<website>\<novel>\`, the
  window's logs in `files\runtime-data\logs\`.
- **Evidence for the review:** keep it in `files\test-logs\v0.3.0_owner-acceptance\` (ignored by Git):
  the setup window's text (select all, copy, paste into a `.txt`), screenshots where useful, the session
  logs, and for every run folder the checker's report:
  `.venv\Scripts\python files\audit_run.py "<run folder>" --pdf-text --json "<evidence folder>\<run>.json"`
  It prints counts, gaps, repeats, file checksums and heading checks (never chapter text) and ends with
  "All checks passed." or a list of problems.
- **Politeness:** keep the default 3-second delay, run one full novel at a time, and stop if a site
  starts failing broadly (Resume continues later). A Free Web Novel (.com) run may open a visible
  browser window: leave it open and on screen.
