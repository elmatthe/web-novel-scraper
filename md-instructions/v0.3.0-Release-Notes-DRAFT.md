# Web Novel Scraper v0.3.0 — release notes (DRAFT, Unreleased)

Temporary drop. Publish only after the owner approves: whole-novel runs and the independent review
must be done first (see `handoff.md`). Windows 10/11 only.

## Install
1. Download the source **ZIP** from the GitHub release page (or "Code → Download ZIP"), extract the whole
   ZIP somewhere short and writable (Downloads or Desktop).
2. Double-click **`Setup_and_Run-Web-Novel-Scraper.bat`**. It sets up everything inside the folder
   (and offers to install Python 3.12 for your account if no Python 3.12/3.13 is found).
3. Later starts use the same file and repair anything missing.

## What's new
- **Reliable long runs:** each run gets its own numbered folder with a checksummed record; **Stop** is
  clean and **Resume Existing Run** redoes only what is missing. A resume never replaces a fuller file.
- **Chapter lists you can trust:** saved lists update themselves; an End past the last chapter is lowered
  to it (and a Start beyond the end is refused); gaps in a website's own list are reported, never guessed.
- **PDF and/or TXT**, one `Chapter N: Title` heading per chapter, clutter removed, text otherwise kept.
- **Two new novels** — *Lord of the Mysteries* and *Lord of Mysteries 2* — on Free Web Novel (.com) and (.net).
- **Self-repairing Windows setup**, with plain explanations for too-long or read-only folders.
- **New window:** Light/Dark, Activity (Summary/Detailed), progress with ETA; the preparing bar now glides
  and the ETA ignores instantly-loaded saved pages.
- Fixed: .net *Lord of the Mysteries* chapter 1303 (misspelt address on the site) was skipped.

## Known limits
- Windows only; macOS is planned for a later release.
- Free Web Novel (.com) sits behind Cloudflare: a browser window may appear and must stay on screen.
- Whole-novel downloads take hours at the polite default delay; use Resume if a run is interrupted.
- Some websites' own lists omit or leave untitled a few chapters; the app reports them.
