# v0.3.0 — Windows owner acceptance and independent review

Temporary instruction drop (delete it once v0.3.0 is released). Part 1 is the owner's acceptance
checklist; Part 2 is the copy-ready prompt for the independent GO/NO-GO review. Nothing here has
been run by the owner yet: every box below starts unticked.

## Before you start

- **Where things go:** runs land in `Downloads\Web-Novel-Scraper-Outputs\<novel>-N\` (`PDF\`, `TXT\`,
  plus `run-journal.jsonl`, `run-selection.json`, `run-audit.json`). Saved chapter lists are in
  `files\runtime-data\chapter-lists\<website>\`, saved pages in `files\cache\<website>\<novel>\`, the
  window's logs in `files\runtime-data\logs\`.
- **Evidence for the review:** keep it in `files\test-logs\v0.3.0_owner-acceptance\` (ignored by Git):
  the setup window's text (select all, copy, paste into a `.txt`), screenshots where useful, the session
  logs, and for every run folder the checker's report:
  `.venv\Scripts\python files\audit_run.py "<run folder>" --pdf-text --json "<evidence folder>\<run>.json"`
  It prints counts, gaps, repeats, file checksums and heading checks (never chapter text) and ends with
  "All checks passed." or a list of problems.
- **Politeness:** keep the default 3-second delay, run one full novel at a time, and stop if a site
  starts failing broadly (Resume continues later). A Free Web Novel (.com) run may open a visible
  browser window: leave it open and on screen.

## Part 1 — Owner acceptance checklist

### A. Once (items 1–3)

- [ ] **1. Clean rebuild.** Close the program. Delete the `.venv` folder in the project folder.
      Double-click `Setup_and_Run-Web-Novel-Scraper.bat`.
      Expect: Step 1 "will be (re)built" and "Using Python 3.13.x (or 3.12.x) at …", Step 2 installs the
      packages, Step 3 downloads only Camoufox's GeoIP data (the browsers themselves are kept) and says
      "Browser engines are ready.", Step 4 opens the window. Note how long it took.
- [ ] **2. Repair and start-up.** Close the window (the setup window says "Program finished."), then
      double-click again: no installs, the window opens within a few seconds, no warning in the
      Activity Summary. Optional: rename `files\bin\ms-playwright` temporarily and start again; Step 3
      should name Chromium as missing and download it (about 150 MB), then rename your copy back or
      delete it.
- [ ] **3. Window.** Light/Dark (bottom right), a narrow and a wide window (all controls usable),
      Windows display scaling 125% or 150% if you can (text sharp, nothing cut off), Advanced
      Settings opens and closes, Activity Summary/Detailed tabs and Clear Log, progress bar and ETA
      moving during a run.

- [ ] **4. Small range.** Run the small range above with PDF only, "Individual chapters". Open the
      files: one heading per chapter (`Chapter N: Title`), story text complete, no site menus,
      comment prompts or "read on …" adverts. P7: Summary reports chapter 1303 as not on the site's
      list, and 4 files are written.
- [ ] **5. Formats and grouping.** Same range with TXT only, then both, then "Every 2 chapters per
      file", then "Whole selected range". TXT and PDF hold the same chapters in the same order; files
      land in `PDF\` and `TXT\`; you cannot untick both formats.
- [ ] **6. Large End.** Start = latest chapter − 2, End = 99999. Expect a "range adjusted" note
      (End lowered to the latest chapter) and only the real last chapters saved. A Start past the last
      chapter says none are available and writes nothing.
- [ ] **7. New chapters and caching.** Start near the latest chapter, End blank. Detailed shows the
      chapter list being checked ("Building chapter index (TOC) …" and either "discovered N chapters;
      saved the chapter list." or "matches the saved chapter list"). For an ongoing novel, repeat after
      the site posts a new chapter: it is found and saved.
- [ ] **8. Repeat run from saved pages.** Run the small range again. The run is quick, and the summary in
      Detailed says "From the saved-page cache: N chapter page(s), no request to the site".
- [ ] **9. Explicit refresh.** Advanced Settings → tick "Re-download saved chapter pages on the next
      run" → run the small range: no saved-page line (pages fetched fresh); the box clears itself.
      Tick "Refresh chapter list on the next run" → run: the list is rebuilt and a
      `<novel>.json.bak-<time>` backup appears in `files\runtime-data\chapter-lists\<website>\`.
- [ ] **10. Stop and Resume.** Run about 30 chapters, "Every 10 chapters per file", press Stop part-way.
      Then Resume Existing Run → pick that run. Detailed: "… already saved and verified by checksum;
      skipping them."; only the missing work is done; `audit_run.py` on the folder passes.
- [ ] **11. Whole novel.** Start 1, End blank, PDF and TXT, a grouping of your choice. Let it finish (a
      .com novel can take a few hours at the default delay). If chapters fail, use Resume later.
- [ ] **12. Inspect.** Run `audit_run.py … --pdf-text --json …` on the full run: chapter count equals
      the site's, in order, no repeats, gaps only where the site's list has them, every file "ok",
      headings match. Open the first, a middle and the last file of each format; check a chapter with
      quotes, dashes or non-English characters for correct characters.

Not exercised by the developer and worth one look if you have a way to: a PC with no Python at all
(the setup window should offer to install Python 3.12 for your user only), and a display at 125%/150%.
